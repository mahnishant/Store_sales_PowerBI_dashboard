# 📊 Store Sales Forecasting Dashboard | Power BI Project

This project showcases a comprehensive **Power BI dashboard and forecasting solution** designed to analyze historical sales data and predict future trends using **time-series analysis techniques**.

## 🚀 Project Overview

The dashboard was developed to help retail businesses:

- Monitor **sales, profit, and quantity trends**
- Segment performance by **region, category, sub-category, and shipping mode**
- Forecast upcoming sales for **better inventory and operational planning**
- Track key metrics like **monthly/yearly growth**, customer segmentation, and **state-wise performance**

## 📌 Key Features

- 🕒 **Time-Series Forecasting:** Built-in 15-day future sales forecast using Power BI’s predictive analytics.
- 📈 **Sales KPIs:** Total Sales, Profit, Ship Days, Quantity, State/Region-wise Distribution.
- 🎯 **Customer Segmentation:** Analysis by Segment (Consumer, Corporate, Home Office).
- 🗺️ **Geo Insights:** Sales breakdown by U.S. States.
- 🛍️ **Sales by Product Hierarchy:** Category & Sub-category level analysis.
- 💳 **Sales by Payment Mode and Ship Mode**

## 🔍 Tools & Technologies

- **Power BI Desktop**
- **Time-Series Analysis**
- **DAX for calculated measures**
- **Interactive filters and slicers**

## 📊 Visualizations

- Sales Forecast (15 Days, Trend Line)
- Year-over-Year Monthly Sales & Profit
- Sales by Segment, Category, Sub-Category
- State-wise and Region-wise Sales Maps
- Dynamic KPI Cards
